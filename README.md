Customer Tracking System
A comprehensive ASP.NET Core MVC web application for managing customer information with advanced filtering, sorting, and pagination capabilities.

Features
Customer Management: Full CRUD (Create, Read, Update, Delete) operations

Advanced Filtering: Filter customers by name and VAT number

Smart Sorting: Sort by name or VAT number in ascending/descending order

Pagination: Efficient data display with 10 records per page

Responsive Design: Clean, modern UI that works on all devices

Data Validation: Robust server-side and client-side validation

Entity Framework: Built with EF Core for reliable data access

Security: Anti-forgery tokens and secure data handling

Technology Stack
Framework: ASP.NET Core 8.0 MVC

Database: Entity Framework Core with SQL Server

Frontend: HTML5, CSS3, JavaScript, Bootstrap

Authentication: ASP.NET Core Identity (ready for implementation)

Deployment: Azure App Service ready
